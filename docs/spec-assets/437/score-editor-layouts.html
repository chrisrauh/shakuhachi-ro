How to use

Three palette columns: notes, length and octave, marks, with the edit controls fixed at the bottom. The ⇄ button at the top of the editor moves the palettes to the other side.

Tap a note to highlight it, and tap it again for a cursor after it. Tap between notes for a cursor there.

With a cursor, a note is inserted. With a highlight, it replaces the note. Durations and marks change the highlighted note, or the note before the cursor.

An empty score. Choose a note to start.
