# Other Kinko charts: fingerings Koga doesn't name (draft for review)

What four Kinko charts add to Koga's (`koga-inventory.md`), per decision 2 on #430: other charts fill only where Koga is silent. ⚠ marks an uncertain reading. Tozan and Zensabō charts are left for later.

Holes are written 5·4·3·2·1, as in the Koga inventory: ● closed, ○ open, ◐ half, ◕ mostly, ◔ slightly covered. Pitches are written notes for a 1.8 in D.
