# Fingering charts

Reference charts for the fingering → pitch table (`src/web-component/constants/kinko-pitch-map.ts`, #417 / #430).

**Koga's charts are canonical.** They come from Masayuki Koga's *Shakuhachi: Japanese Bamboo Flute*, a book in two volumes:

- *Koga I*: Section 1, Fundamental Techniques. Pages 37 and 39.
- *Koga II*: II. Advanced, III. History. Pages 107–109.

Where they and another chart disagree, Koga wins. The other charts fill in only where Koga is silent, including Tozan and Zensabō fingerings that Kinko lacks.
