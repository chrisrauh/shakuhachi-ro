# Fingering charts

Reference charts for the fingering → pitch table (`src/web-component/constants/kinko-pitch-map.ts`, #417 / #430).

**Koga's charts are canonical.** Where they and another chart disagree, Koga wins. The other charts fill in only where Koga is silent, including Tozan and Zensabō fingerings that Kinko lacks.
