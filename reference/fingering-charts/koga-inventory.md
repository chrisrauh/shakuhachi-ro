## How to read it

- **Pitch:** the written note for a standard 1.8 shakuhachi in D. Koga prints a note above only the first column of each group. A column without a note is an alternative fingering for the pitch of the nearest noted column before it. This rule matches every named column whose pitch is known, e.g. 29 kan ro meri = D♭5.
- **Holes:** in the chart's order, top to bottom: back (thumb) hole 5, then front holes 4, 3, 2, 1, with 1 nearest the bottom of the flute. Checked against the drawing of the flute on page 37.
  - ● closed
  - ○ open
  - ◐ half covered
  - ◕ mostly covered
  - ◔ slightly covered

  Half covering in the photos is shown in degrees, and the degree is often hard to judge.
- **Name:** written as in the chart, for example ツメ for tsu no meri. "—" means Koga gives no name for that fingering.
- **Octave:** 乙 otsu, 甲 kan, 大甲 daikan, as the name implies.

## Observations for the table design

- **33 of the 84 fingerings have a Kinko name; the other 51 are unnamed alternatives.** The data model needs names only for the named ones. The unnamed ones can still be stored as alternative hole patterns for their pitch, for fingering diagrams later.
- **Same holes, different pitch.** Several names share a hole pattern and differ only in embouchure (meri):
  - #1–3: ro dai-meri, ro meri, ro;
  - #29–30: kan ro meri, kan ro;
  - #5–6: tsu meri, tsu chu-meri.

  So holes alone can't identify a fingering. The name is the key, and holes are attached data.
- **Koga differs from the current table** (`kinko-pitch-map.ts`). Koga is canonical, so these change:
  - B♭4 is ri meri (#19), not chi meri.
  - B♭5 is hi meri (#52), and B5 is hi chu-meri (#56), not chi chu-meri and ri.
  - A♭5 is chi meri (#45), which agrees with the table. A♭4 is u (#12), which also agrees.
